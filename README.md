# Zomato Restaurant Analysis and Classification

## Project Overview

This project analyzes Zomato restaurant data using Python and Power BI. It also uses Machine Learning to classify restaurants based on their price range.

## Objectives

* Analyze restaurant data
* Clean and prepare the dataset
* Perform Exploratory Data Analysis (EDA)
* Find useful patterns and insights
* Build classification models
* Evaluate the machine learning models
* Create a Power BI dashboard

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Power BI
* Google Colab

## Machine Learning Models

* Logistic Regression
* Decision Tree
* Random Forest

## Project Steps

1. Data Collection
2. Data Loading
3. Data Cleaning
4. Missing Value Handling
5. Duplicate Removal
6. Exploratory Data Analysis
7. Data Visualization
8. Feature Engineering
9. Feature Selection
10. Categorical Data Encoding
11. Train-Test Split
12. Data Scaling
13. Model Training
14. Prediction
15. Model Evaluation
16. Model Comparison
17. Power BI Dashboard
18. Final Conclusion

## Evaluation Metrics

The classification models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## Dashboard

A Power BI dashboard was created to display important restaurant insights using charts and visualizations.

## Conclusion

This project demonstrates how data analysis, machine learning, and visualization can be used to understand restaurant data and generate useful insights.
