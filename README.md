# Zomato Restaurant Analysis and Machine Learning
## Project Overview
This project analyzes Zomato restaurant data using Python and Power BI.
The project includes data cleaning, Exploratory Data Analysis (EDA), Machine Learning, and dashboard creation.

Machine Learning classification models are used to classify restaurants based on their rating category.

## Objectives

* To clean the Zomato dataset
* To analyze restaurant data
* To perform Exploratory Data Analysis
* To find useful patterns and insights
* To train Machine Learning classification models
* To evaluate the models
* To create a Power BI dashboard

## Dataset

The dataset contains information about restaurants, such as:

* Restaurant Name
* Location
* Rating
* Votes
* Cost for Two
* Online Order
* Book Table
* Restaurant Type
* Cuisines
